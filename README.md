## Create projects

1. Open Gitbash

2. Create API .NET Solution

```cmd
$dotnet --info
$dotnet -h
$dotnet new list
$dotnet new sln
$dotnet new webapi -o [APIName] -controllers
$dotnet new classlib -o [LibName]

$dotnet sln add [projectName]

$dotnet add reference ../infrastructure

$dotnet restore
$dotnet run

$dotnet watch

```
